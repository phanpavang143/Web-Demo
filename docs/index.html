The application keeps the local development loop simple while providing clear seams for AWS storage, messaging, observability, and deployment.

02

03

04

Quality gates

Maven verification, health endpoint coverage, Terraform validation workflow, and GitHub Actions CI.

AWS path

Private by default. Observable in production.

Traffic enters through an Application Load Balancer and reaches private ECS Fargate tasks. IAM task roles connect the application to S3, SQS, and CloudWatch without long-lived keys in the container.
